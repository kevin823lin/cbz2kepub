# 驗證結果

驗證環境：Windows、Python 3.13.7，KCC 固定 `d170828`。

| 項目 | 結果 |
|---|---|
| 單元測試 | 主專案 63 項、KCC 30 項，共 93 項通過 |
| CLI 整合 | 5 個情境、8 次轉換通過，包含跨工作目錄啟動 main.py、分卷、metadata 與不備份重跑 |
| 實際資料 | 70 個 CBZ、2,929 個正文頁、70 個正確章節入口 |
| 成品 | 1 卷，1,328,139,120 bytes，低於 2 GB 上限 |
| 封面 | 第一個閱讀頁且置中；1260×1680 JPEG 與獨立重建參考圖一致 |
| Metadata | 作者、簡介及尾端換行、系列名與卷序均正確 |
| 完整性 | ZIP CRC、XML、資源引用、正文及章節順序通過；來源 SHA256 未變 |
| 工作區 | 70 個 CBZ 使用硬連結；成功後無工作目錄、交易或鎖殘留 |

測試與驗收命令見 [開發指南](contributing.md#測試)。

尚未涵蓋 Kobo 實機、全面畫質比較、全新環境重建，以及實體跨磁碟／斷電測試；一般容量不足與發布失敗已用受控測試驗證。
